# SKVOZNYAK v0.4 — Data Mapping

## Meta Ads

Источник — только семь оригинальных CSV, апрель–октябрь 2026. Идентификаторы читаются как строки; `ID рекламы` обязан соответствовать `^\d{18}$`. Расход относится к `Дата начала отчетности`.

| Модель | Исходное поле |
|---|---|
| report_date | Дата начала отчетности |
| ad/account/campaign/adset ID | ID рекламы / Идентификатор аккаунта / Идентификатор кампании / ID группы объявлений |
| spend_usd | Потраченная сумма (USD) |
| impressions / daily reach | Показы / Охват |
| link clicks / all clicks | Клики по ссылке / Клики (все) |
| results / result type | Результат / Индикатор результата |
| messaging | Начата переписка / Всего контактов по переписке / Новые контакты по переписке |

Периодный reach не рассчитывается суммой дневного reach. Last Spend и Last Observed Activity не интерпретируются как фактическое отключение.

## amoCRM

Уникальная сущность — сделка по `ID`. Exact attribution строится по полному `FB ad id`. CTWA подтверждается только при одновременном exact Ad ID и непустом `FB CTWA`.

Квалифицированный лид: только `Квалифицированный = да`. `нет` и пустое значение различаются. Поле `Квалифицирован` хранится отдельно как класс/срочность.

Creative URL, headline и text берутся из `FB URL`, `FB Headline`, `FB Text` для того же exact Ad ID. Публично разрешены только HTTPS Instagram post/reel/tv и `fb.me` без query/fragment; WhatsApp preview исключаются.
